📖 VISUAL ENCYCLOPEDIA NODE // VIRTUALIZATION & HIGH AVAILABILITY

P2V (Physical to Virtual): The process of converting an operating system and state running on physical bare-metal hardware into a virtual disk/VM image.
vMotion / Live Migration: Moving an active, running virtual machine from one physical hypervisor host to another with zero perceived downtime.
Hypervisor Type 1 (Bare-Metal): Runs directly on hardware (ESXi, Hyper-V, KVM) for maximum throughput and enterprise resilience.

🛡️ CLOUD+ & NETWORK+ EXAM SHOWDOWN // VM VS CONTAINER

Virtual Machine (VM): Includes a full guest operating system, virtual drivers, and virtualized hardware. Heavyweight (Gigabytes), minutes to boot, managed by a Hypervisor.
Container (Docker): Packages only application code and dependencies, sharing the host OS kernel. Lightweight (Megabytes), launches in sub-seconds, portable anywhere.
Geo-Redundancy: Storing snapshots and container pods across multiple geographic regions (e.g. EU-West-2 and US-East-1) to ensure five-nines (99.999%) availability.
