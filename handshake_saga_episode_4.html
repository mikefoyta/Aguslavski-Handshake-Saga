📖 VISUAL ENCYCLOPEDIA NODE // MTU & TCP SEGMENTATION

Maximum Transmission Unit (MTU): Standard Ethernet frames carry a maximum payload of 1,500 bytes. Large files (videos, database records) must be divided into thousands or millions of TCP Segments at Layer 4, each marked with an incremental Sequence Number so the destination can reassemble them in order.

🛡️ CCNA & NETWORK+ EXAM SHOWDOWN // SACK VS UDP STREAMING

Selective Acknowledgement (SACK): In classic TCP, a missing packet forced retransmitting EVERYTHING after the missing sequence. SACK allows the receiver to say: "I have 1-4 and 6-100; only resend #5." This saves immense network bandwidth.
UDP Alternative (Live VoIP / Gaming): UDP has NO sequence numbers, NO buffers, and NO retransmissions. If Packet #5 is lost in a live voice call, it is simply skipped, resulting in a brief audio glitch.
