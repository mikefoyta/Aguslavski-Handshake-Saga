📖 VISUAL ENCYCLOPEDIA NODE // THE AAA TRIAD

1. Authentication (Who are you?): Verification of username, password, certificates, or tokens.
2. Authorization (What can you do?): Group policies determining VIP access vs. guest quarantine.
3. Accounting (What did you do?): The timestamped tab tracking session duration, data transferred, and actions logged.

🛡️ CCNA & NETWORK+ EXAM SHOWDOWN // RADIUS VS TACACS+

RADIUS (Remote Authentication Dial-In User Service): Combines authentication and authorization. Encrypts ONLY the password. Uses UDP ports 1812/1813. Common for network access (802.1X, Wi-Fi).
TACACS+ (Terminal Access Controller Access-Control System): Separates Authentication, Authorization, and Accounting. Encrypts the WHOLE session. Uses TCP port 49. Standard for router and switch device administration.
