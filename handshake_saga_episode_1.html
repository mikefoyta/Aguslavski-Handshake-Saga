📖 VISUAL ENCYCLOPEDIA NODE // THE OSI 7 LAYERS

• Layer 7 (Application): HTTP/S, DNS, SSH — User interaction.
• Layer 6 (Presentation): TLS/SSL Encryption, compression, data format.
• Layer 5 (Session): RPC, NetBIOS — Maintains state between endpoints.
• Layer 4 (Transport): TCP/UDP — Port numbers & sequencing (Segment).
• Layer 3 (Network): IPv4/IPv6 — Logical routing across WANs (Packet).
• Layer 2 (Data Link): MAC addresses & Frame Check Sequence (Frame).
• Layer 1 (Physical): Copper voltages, optical laser pulses, RF radio (Bits).

🛡️ CCNA & NETWORK+ EXAM FLASHCARDS // PDUs

Protocol Data Units (PDUs):
• Layer 4 PDU = Segment (TCP) or Datagram (UDP).
• Layer 3 PDU = Packet (IP Header + Payload).
• Layer 2 PDU = Frame (Header + Packet + Trailer/FCS).
• Layer 1 PDU = Bits (Physical transmission of 1s and 0s).
