📖 VISUAL ENCYCLOPEDIA NODE // RFC 1918 PRIVATE IP RANGES

To conserve IPv4 addresses and protect internal topologies, RFC 1918 allocated three private blocks that CANNOT be routed on the public internet:
• Class A: 10.0.0.0 to 10.255.255.255 (/8) — Enterprise scale.
• Class B: 172.16.0.0 to 172.31.255.255 (/12) — Corporate cloud subnets.
• Class C: 192.168.0.0 to 192.168.255.255 (/16) — Home & local branch offices.

🎙️ CCNA & NETWORK+ NETWORKING FLASHCARDS

Cleartext Risks: Telnet (Port 23) and FTP (Port 20/21) send all user credentials in clear, unencrypted text. Modern security baselines mandate SSH (Port 22) and SFTP/HTTPS.
Quality of Service (QoS): Voice over IP (VoIP) and live video cannot tolerate latency or jitter (delay variation). Network switches and routers use QoS priority queuing (DSCP/CoS) to push voice packets ahead of bulk data like email and downloads.
